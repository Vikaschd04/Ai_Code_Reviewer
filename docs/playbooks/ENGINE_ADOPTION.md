# Playbook — Add or upgrade an engine

Read ENGINE_ADOPTION.md and ANALYSIS_PIPELINE.md in the parent docs directory. Confirm the requested engine solves a concrete coverage gap.

1. Inspect current official release/license/config/output documentation and record exact pins.
2. Define capability/input/coverage/failure/cancel contracts before integration.
3. Implement isolated execution and normalization; retain raw artifacts.
4. Add real positive/negative fixtures and crash/timeout/malformed-output cases.
5. Verify path/range and rule provenance, duplicate correlation, budgets and network behavior.
6. Run relevant integration checks and record adoption/upgrade decision.

Do not infer commercial rights from a compatible rule format. Do not accept tool failure as a clean scan. This is a project playbook, not an installed skill.
