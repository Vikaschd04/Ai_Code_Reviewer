# Playbook — Verify a phase

Read the phase prompt, PHASE_STATUS and actual implementation/tests. Compare each mandatory gate with concrete evidence. Run the smallest relevant checks needed to resolve uncertainty, plus the required phase integration/E2E gates.

Look specifically for fake findings, placeholder adapters, skipped gates, stale source references, incomplete coverage, authorization gaps and untested startup instructions. Inspect the UI for changed user workflows. Do not rewrite tests to accept wrong behavior.

Write a phase report, update status and give the next actionable task. Documentation existence is not feature implementation. This is a playbook, not an installed skill.
