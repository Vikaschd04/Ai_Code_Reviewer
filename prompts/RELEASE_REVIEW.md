# Review release readiness

Inspect the actual release candidate and shipped configuration, all applicable phase evidence, capability/version matrix, engine/rule licenses, installation docs and operations runbooks. Do not rely on a roadmap checkbox.

Verify mandatory security/access/isolation, input and prompt-injection boundaries, exact source/fix identity, recovery/deletion, measured capacity/cost, dependency pinning, UI/accessibility, supported domain accuracy and conditional platform checks.

Create or update docs/validation/RELEASE_READINESS.md with READY_FOR_REVIEW or BLOCKED, supported scope, concrete evidence, measured limits, residual risks and named missing prerequisites. Do not certify compliance or declare production readiness from a build alone. This prompt authorizes a review, not deployment, external messages, paid resources or production mutations.
